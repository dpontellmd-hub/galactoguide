records → Add Record**. These enable signup and password-reset email from
`no-reply@auth.galactoguide.com`.

The values below were generated by Resend for this exact sending domain on
2026-09-19. Use the Host names exactly as shown; Squarespace adds
`.galactoguide.com` automatically. Use the default **4-hour TTL**. Priority does
not apply to these TXT/CNAME records.

## Finish

Save all three records and tell the person configuring GalactoGuide that they
have been added. Keep the existing `www`, `_domainconnect`, and Email Security
records unchanged. No website redirect or nameserver change is needed for this
email setup.

We will then verify the records in Resend, connect the sender to Supabase, and
test signup and password-reset email delivery. Adding these records alone does
not complete the Supabase email setup.
